# Homebrew Tap

## Howler

Install [Howler](https://howler.arieszhou.com/), a macOS 14+ menu bar app for quick AI questions:

```sh
brew install --cask hiarieszhou/tap/howler
```

The cask installs the signed, notarized universal app from a versioned GitHub Release
and verifies its SHA-256. Subsequent updates are available inside Howler.

## LiteContext

Install LiteContext:

```sh
brew install Aries-0331/tap/litecontext
```

The formula builds `lc` from the immutable source archive attached to each
[LiteContext GitHub Release](https://github.com/Aries-0331/litecontext/releases).
